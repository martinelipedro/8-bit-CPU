# Registradores

Tabela de registradores e seus códigos (4 bits):

| Registrador | Código | Observação |
|---|---:|---|
| A | 0 | Acumulador |
| B | 1 | Multipurpose |
| C | 2 | Contador up/down (loops) |
| PAGE | 3 | Paginação de endereços |
| 7SEG | 4 | Saída para display 7 segmentos |
| LCD | 6 | Saída para display LCD |
